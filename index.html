Java script

O que é JavaScript?

É uma linguagem de programação muito utilizada para criar aplicações interativas e sistemas de Software.

Ele é responsável por:

  • Responder a cliques
  • Validar formulários
  • Atualizar conteúdos
  • Buscar dados de APIS
  • Controlar o comportamento da aplicação

IMPORTANTE: Apesar das semelhanças nos nomes, são linguagens totalmente diferentes, com características e ecossistemas próprios.

Curiosidade: Foi criado em apenas 10 dias.

O que mais dá pra fazer com JS?

  • Frontend
    • Criar interfaces interativas
    • Menus
    • Validações
    • Filtros
    • Animações
    • Dashboards
    • Aplicações com React, Vue, Angular, Astro, etc.
  • Backend
    • Nodejs
    • Criar APIS REST
    • Autenticação
    • Processar requisições
    • Integrar com serviços de bancos de dados
    • Nodejs
  • Mobile desktop
    • Criar aplicativos
    • React Native e Electron
